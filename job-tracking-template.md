# Job Tracking Template

Use one row per job opportunity.

| Date Seen | Company | Role | Location | Source | Match Score | Why It Fits | Missing Skills | Status | Apply Link | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  | LinkedIn / Naukri / Instahyre / Wellfound / Cutshort / Company site |  |  |  | Seen / Shortlisted / Applied / Rejected / Ignored |  |  |

## Status Meaning
- Seen: job has been discovered but not reviewed fully.
- Shortlisted: good fit and worth applying to.
- Applied: application submitted.
- Rejected: not a fit or explicitly ruled out.
- Ignored: company or role should not show up again.

## Optional Fields to Track
- Recruiter contact
- Application date
- Interview stage
- Follow-up date
- Salary range
- Notes on company culture or tech stack
